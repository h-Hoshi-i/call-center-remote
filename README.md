# call-center-remote

This is a "remote" that makes accessing the code I wrote for the various campaigns used in my office easily accessible for me and my coworker.

To get it working, click the latest release and download the .exe file.

LIMITATIONS:
Due to the limitations of coding at work, the goal is to make the code functional and easily modifiable, rather than efficient. ie. accounting for edge cases, or shaving off milliseconds from the runtime.
Additionally I do not have admin while at work, so all my code must be written using libraries that do not require administrator privileges. 
Finally, because while at work I have expectations of completion, coding is not the priority, so deep diving into learning the in's and out's of a library are not possible.

AI:
I tried to keep the use of AI to a minimum. the most notable uses are the clear_screen() function and the first attempt at a lambda function. Although i did modify it for my use, the clear_screen() function is entirely AI as i could not figure out how to clear the "screen" for each page of the remote. As for the first use of the lambda function, i was looking up how to add parameters to a command in the button when i saw i could use the lambda function. I than did a bit of research myself so i could implement it, but i mention it because the idea did not come from me, rather an AI.
